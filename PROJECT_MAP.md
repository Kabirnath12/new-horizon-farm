## Learning order

1. Read `index.html` → HTML structure.
2. Read `style.css` → layout/responsive design.
3. Read `script.js` → JavaScript + DOM + events.
4. Run the backend → Node/Express/API.
5. Connect the frontend to the API.
6. Later replace the in-memory arrays with MongoDB.
7. Add auth, admin, orders, payments, Redis, tests, Docker and deployment.
